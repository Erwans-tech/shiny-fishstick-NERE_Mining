================================================================================
                      REQUIRED SETUP (5-15 minutes)
================================================================================

On Your Server:
  1. Generate SSH key: ssh-keygen -t ed25519
  2. Add public key to authorized_keys
  3. Verify SSH access works

In GitHub:
  1. Settings → Secrets and variables → Actions
  2. Add 4 secrets:
     - DEPLOY_HOST (your server IP)
     - DEPLOY_USER (SSH username)
     - DEPLOY_SSH_KEY (private key content)
     - PROJECT_PATH (project directory)

Optional:
  - Add SLACK_WEBHOOK_URL for notifications

================================================================================
                          HOW TO DEPLOY
================================================================================

After setup is complete, deploying is simple:

  $ git push origin production

That's it! GitHub Actions will:
  1. Detect the push
  2. Trigger the deployment workflow
  3. SSH to your server
  4. Pull latest code
  5. Install dependencies
  6. Run migrations
  7. Restart services
  8. Send notification

Total time: 3-4 minutes from push to live

================================================================================
                        SUPPORT & TROUBLESHOOTING
================================================================================

If you encounter issues:

1. Check GitHub Actions logs
   - Go to Actions tab
   - Click the failed workflow
   - See detailed error messages

2. Check server logs
   - SSH to server
   - tail -f storage/logs/laravel.log
   - tail -f /var/log/nginx/error.log

3. Common issues:
   - "Permission denied" → Check SSH key permissions
   - "Composer not found" → Install composer on server
   - "DB connection failed" → Check .env file
   - "500 error" → Check laravel logs

4. Full troubleshooting:

================================================================================
                        FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Do I need to SSH to the server to deploy?
A: No! Just push to the production branch. GitHub Actions handles everything.

Q: What if deployment fails?
A: Backups are automatic. Restore from backup and check logs for the error.

Q: Can I deploy without pushing code?
A: Yes! Use GitHub Actions "Run workflow" button for manual deployments.

Q: How long does deployment take?
A: Typically 3-4 minutes from push to live.

Q: What if I need to rollback?
A: Backups are created before each deployment. SSH to server and restore.

Q: Do I need Docker?
A: No! Docker configuration is optional. SSH deployment works with traditional hosting.

Q: Can multiple people deploy?
A: Yes! Anyone with push access to production branch can trigger deployments.

Q: How do I monitor deployments?
A: Watch GitHub Actions tab. Slack notifications available (optional).

Q: What database engines are supported?
A: MySQL, MariaDB, PostgreSQL - whatever Laravel supports.

Q: Can I deploy to multiple servers?
A: Yes! Create additional secrets for additional servers.
