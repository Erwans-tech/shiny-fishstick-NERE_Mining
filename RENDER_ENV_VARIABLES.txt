🔑 Variables d'environnement pour Render Dashboard
========================================================

Copie-colle ces variables exactement dans ton dashboard Render :
https://dashboard.render.com → ton service → Environment

# Application
APP_NAME=Néré Mining
APP_ENV=production
APP_DEBUG=false
APP_URL=https://nere-mining.onrender.com
FORCE_HTTPS=true

# Base de données Supabase (PostgreSQL)
# ⚠️  Valeurs réelles dans le dashboard Render / dashboard Supabase.
#     Jamais dans le dépôt Git.
DB_CONNECTION=pgsql
DB_HOST=<votre-hote-supabase>
DB_PORT=5432
DB_DATABASE=postgres
DB_USERNAME=<votre-user-supabase>
DB_PASSWORD=<mot-de-passe-supabase>

# Session & Sécurité
SESSION_DRIVER=file
SESSION_SECURE_COOKIE=true
SESSION_SAME_SITE=strict
BCRYPT_ROUNDS=12

# Logs & Performance
LOG_CHANNEL=daily
LOG_LEVEL=warning
CACHE_DRIVER=file
QUEUE_CONNECTION=sync
FILESYSTEM_DISK=public

# Mail (optionnel)
MAIL_MAILER=log
MAIL_FROM_ADDRESS=contact@nere-mining.com
MAIL_FROM_NAME=Néré Mining

========================================================
⚠️  IMPORTANT : N'oublie pas de générer APP_KEY dans Render !
🔗 Render génèrera automatiquement une clé sécurisée.
========================================================
